Nous avons choisi la pile : le dernier élément ajouté est le premier retiré (LIFO). Elle est implémentée en deux versions, pour pouvoir comparer leur performance réelle.

VersionPosition du sommetEmpilerDépiler
Efficacefin de la listeappend(x)pop()
Naïvetête de la listeinsert(0, x)pop(0)

Toute la différence tient à l’endroit où l’on place le sommet dans la liste Python.

  • Encapsulation : l’état est stocké dans _items (préfixe _ = privé). L’extérieur n’utilise que l’interface.
  • Interface : empiler, depiler, sommet, est_vide, __len__, __str__.
  • Cas d’erreur : depiler() et sommet() sur une pile vide lèvent StructureVideError au lieu d’une IndexError peu explicite.

Code complet : structures.py

# -*- coding: utf-8 -*-
"""
structures.py : deux versions d'une pile (LIFO), efficace et naive.

Python 3.10+
"""

from __future__ import annotations


class StructureVideError(Exception):
    """Levée lorsqu'on tente de retirer ou de consulter un élément d'une structure vide."""


class PileEfficace:
    """Pile (LIFO) : ajouts et retraits en fin de liste, O(1) amorti par opération.

    Le sommet est le DERNIER élément de la liste interne.
    """

    def __init__(self) -> None:
        """Crée une pile vide."""
        self._items: list = []

    def empiler(self, x) -> None:
        """Ajoute x au sommet de la pile."""
        self._items.append(x)

    def depiler(self):
        """Retire et renvoie le sommet. Lève StructureVideError si la pile est vide."""
        if not self._items:
            raise StructureVideError("depiler() sur une pile vide")
        return self._items.pop()

    def sommet(self):
        """Renvoie le sommet sans le retirer. Lève StructureVideError si la pile est vide."""
        if not self._items:
            raise StructureVideError("sommet() sur une pile vide")
        return self._items[-1]

    def est_vide(self) -> bool:
        """Renvoie True si la pile ne contient aucun élément."""
        return len(self._items) == 0

    def __len__(self) -> int:
        """Nombre d'éléments dans la pile."""
        return len(self._items)

    def __str__(self) -> str:
        return f"PileEfficace(bas->haut = {self._items})"


class PileNaive:
    """Pile (LIFO) qui insère et retire en TÊTE de liste, O(n) par opération.

    Le sommet est le PREMIER élément de la liste interne.
    """

    def __init__(self) -> None:
        """Crée une pile vide."""
        self._items: list = []

    def empiler(self, x) -> None:
        """Ajoute x au sommet (en tête de liste : tous les éléments sont décalés)."""
        self._items.insert(0, x)

    def depiler(self):
        """Retire et renvoie le sommet. Lève StructureVideError si la pile est vide."""
        if not self._items:
            raise StructureVideError("depiler() sur une pile vide")
        return self._items.pop(0)

    def sommet(self):
        """Renvoie le sommet sans le retirer. Lève StructureVideError si la pile est vide."""
        if not self._items:
            raise StructureVideError("sommet() sur une pile vide")
        return self._items[0]

    def est_vide(self) -> bool:
        """Renvoie True si la pile ne contient aucun élément."""
        return len(self._items) == 0

    def __len__(self) -> int:
        """Nombre d'éléments dans la pile."""
        return len(self._items)

    def __str__(self) -> str:
        return f"PileNaive(haut->bas = {self._items})"

Justifications

  • Efficace : append et pop() travaillent en fin de liste sans rien déplacer. « Amorti » car la liste Python est un tableau dynamique : un redimensionnement occasionnel coûte cher, mais ce coût est réparti sur de nombreuses opérations.
  • Naïve : insérer ou retirer en tête oblige à décaler tous les autres éléments d’une position, donc O(n).
  • sommet, est_vide et __len__ ne déplacent rien : O(1) dans les deux versions.

Le banc d’essai effectue n empilements suivis de n dépilements.

  • Version efficace : 2n opérations en O(1) → coût total O(n), courbe à peu près linéaire.
  • Version naïve : 2n opérations en O(n) → coût total O(n²), courbe quadratique.

Prévision : si n est multiplié par 5, le temps de la version efficace est multiplié par environ 5, celui de la version naïve par environ 25. Les mesures (point 8) permettent de le vérifier.

# -*- coding: utf-8 -*-
"""tests.py : jeu de tests des deux versions de la pile (unittest)."""

import unittest

from structures import PileEfficace, PileNaive, StructureVideError


class _TestsPile:
    """Tests communs ; la classe fille fixe la version testée via `fabrique`."""

    fabrique = None

    def setUp(self):
        self.p = self.fabrique()

    def test_pile_vide(self):
        self.assertTrue(self.p.est_vide())
        self.assertEqual(len(self.p), 0)

    def test_erreurs_sur_pile_vide(self):
        with self.assertRaises(StructureVideError):
            self.p.depiler()
        with self.assertRaises(StructureVideError):
            self.p.sommet()

    def test_un_seul_element(self):
        self.p.empiler(42)
        self.assertFalse(self.p.est_vide())
        self.assertEqual(len(self.p), 1)
        self.assertEqual(self.p.sommet(), 42)
        self.assertEqual(self.p.depiler(), 42)
        self.assertTrue(self.p.est_vide())
        with self.assertRaises(StructureVideError):
            self.p.depiler()

    def test_ordre_lifo(self):
        for i in (1, 2, 3, 4):
            self.p.empiler(i)
        self.assertEqual([self.p.depiler() for _ in range(4)], [4, 3, 2, 1])

    def test_sommet_ne_retire_pas(self):
        self.p.empiler("a")
        self.p.empiler("b")
        self.assertEqual(self.p.sommet(), "b")
        self.assertEqual(self.p.sommet(), "b")
        self.assertEqual(len(self.p), 2)

    def test_coherence_len(self):
        for i in range(10):
            self.p.empiler(i)
            self.assertEqual(len(self.p), i + 1)
        for i in range(10):
            self.p.depiler()
            self.assertEqual(len(self.p), 9 - i)

    def test_alternance_empiler_depiler(self):
        self.p.empiler(1)
        self.p.empiler(2)
        self.assertEqual(self.p.depiler(), 2)
        self.p.empiler(3)
        self.assertEqual(self.p.sommet(), 3)
        self.assertEqual(self.p.depiler(), 3)
        self.assertEqual(self.p.depiler(), 1)

    def test_str(self):
        self.p.empiler(1)
        self.assertIn("1", str(self.p))


class TestPileEfficace(_TestsPile, unittest.TestCase):
    fabrique = PileEfficace


class TestPileNaive(_TestsPile, unittest.TestCase):
    fabrique = PileNaive

# -*- coding: utf-8 -*-
"""mesures.py : banc d'essai (temps en fonction de n) et tracé matplotlib."""

import time

from structures import PileEfficace, PileNaive

try:
    import matplotlib
    matplotlib.use("Agg")  # pas de fenêtre : on enregistre directement l'image
    import matplotlib.pyplot as plt
except ImportError:
    plt = None


def mesurer(fabrique, n: int, repetitions: int = 5) -> float:
    """Temps minimal (s) de n empilements suivis de n dépilements.

    Seules les opérations sur la structure sont chronométrées ; la création
    de la structure se fait avant le démarrage du chronomètre.
    """
    temps = []
    for _ in range(repetitions):
        s = fabrique()
        debut = time.perf_counter()
        for i in range(n):
            s.empiler(i)
        for _ in range(n):
            s.depiler()
        temps.append(time.perf_counter() - debut)
    return min(temps)


def experience() -> None:
    """Mesure les deux versions, affiche un tableau et enregistre performance.png."""
    tailles = [1_000, 2_000, 5_000, 10_000, 20_000, 50_000]
    t_eff = [mesurer(PileEfficace, n) for n in tailles]
    t_naif = [mesurer(PileNaive, n) for n in tailles]

    print(f"{'n':>8} | {'efficace (s)':>14} | {'naïve (s)':>12} | {'rapport':>8}")
    for n, te, tn in zip(tailles, t_eff, t_naif):
        print(f"{n:>8} | {te:>14.5f} | {tn:>12.5f} | {tn / te:>8.1f}")

    if plt is None:
        print("matplotlib absent : installez-le pour obtenir le graphique.")
        return

    fig, (ax1, ax2) = plt.subplots(1, 2, figsize=(11, 4))
    for ax in (ax1, ax2):
        ax.plot(tailles, t_eff, marker="o", label="efficace (O(1)/op)")
        ax.plot(tailles, t_naif, marker="s", label="naïve (O(n)/op)")
        ax.set_xlabel("taille n (nombre d'opérations)")
        ax.set_ylabel("temps (s)")
        ax.legend()
        ax.grid(True, alpha=0.3, which="both")
    ax1.set_title("Échelle linéaire")
    ax2.set_xscale("log")
    ax2.set_yscale("log")
    ax2.set_title("Échelle log-log")
    fig.suptitle("Temps d'exécution de n empiler + n dépiler")
    fig.savefig("performance.png", dpi=150, bbox_inches="tight")
    print("Graphique enregistré : performance.png")


if __name__ == "__main__":
    experience()

Temps relevés sur notre machine ; ils varient d’un ordinateur à l’autre, mais la forme des courbes reste la même.

  • La version efficace croît à peu près linéairement : n opérations en O(1).
  • La version naïve croît de façon quadratique : quand n passe de 10 000 à 50 000 (×5), son temps est multiplié par environ 20, proche des 25 attendus.
  • L’écart n’est que de 4 fois à n = 1 000, car le décalage mémoire de insert(0, …) est réalisé en C, très rapidement. Il ne domine que lorsque les listes deviennent grandes (54 fois à n = 50 000).
  • Les petits écarts à la théorie s’expliquent par la constante de l’interpréteur Python, les effets de cache et le ramasse-miettes.

Conclusion

Les mesures confirment l’analyse théorique : O(1) par opération donne un total linéaire, O(n) par opération un total quadratique. Le choix de la structure interne change l’ordre de grandeur du coût.
